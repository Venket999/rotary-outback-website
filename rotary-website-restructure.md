## PART 3: INDIVIDUAL LEADER PAGE TEMPLATE

Each leader gets a dedicated page with this structure:

### Page Components

```
1. HERO SECTION
   - Leader photo (professional headshot)
   - Name + Title (e.g., "Greg Marlow — District Governor 2025-26")
   - One-liner tagline (e.g., "30+ years transforming Rotary into action")
   - Primary CTA: Donate to [Leader's Projects]

2. INTRODUCTION (200-250 words)
   - Personal connection to Rotary (why they joined)
   - Key milestones (written as narrative, not timeline)
   - Current focus area
   - Personal photo or candid action shot

3. PROJECTS SECTION
   - 2-3 featured projects with:
     * Project name & location
     * Impact metric (# people served, $ raised, etc.)
     * Problem → Solution → Impact narrative
     * Project photo/carousel
     * Individual "Donate to This Project" button

4. LEADERSHIP ROLES (if applicable)
   - Timeline of positions held
   - Key achievements in each role

5. IMPACT STATS
   - Visual metric cards (similar to current design)
   - $ Raised | Lives Touched | Communities Served | Years of Service

6. PERSONAL STORY (featured quote)
   - Highlight a personal moment that drives their work
   - 2-3 sentences, italicized
   - Optional: side photo

7. HOW TO SUPPORT
   - 3-tier donation buttons (Quick: $50 | Standard: $250 | Major: $1000+)
   - Monthly giving option
   - Non-monetary ways to engage

8. RELATED LEADERS
   - Show 2-3 other leaders working on similar initiatives
   - Encourage exploration

9. CALL-TO-ACTION FOOTER
   - "Want to work alongside [Name]?" 
   - Primary: Donate button
   - Secondary: Contact / Join Us
```

### Content Tone Principles

✓ **Personal over institutional** — "Greg learned X" not "The district recognized"
✓ **Specific over vague** — "3,447 women educated" not "many women helped"
✓ **Problem → Solution → Impact** — always show the "why" first
✓ **Lead with emotion, back with numbers** — heart first, head second
✓ **Active voice** — "Victoria leads" not "Programs are led"
✓ **Short paragraphs** — 2-4 sentences max for web readability
✓ **Conversational** — like you're explaining to a curious friend

```

   → Primary: "Donate to [Project Name]"
   → Secondary: "Monthly Support"
```
